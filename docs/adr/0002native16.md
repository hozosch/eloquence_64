# Native 16 kHz mode

Version 20 replaces the external 11.025→22.05 kHz output upsampler with a
native 16 kHz Eloquence mode.

## Runtime switching

The original 8 kHz and 11.025 kHz voice data remains the baseline. Those two
rates are native modes of the already-loaded Eloquence engine and can therefore
be changed live through ECI parameter 5.

The 16 kHz mode additionally changes the synthesis module itself. The add-on
stores one compact reversible `.p16` patch for every supported Eloquence voice.
When 16 kHz is selected, the patch is applied to the corresponding `.SYN` file
**before the module is loaded**, and only the 32-bit Eloquence Host Process is
restarted. NVDA itself stays running. Switching back to 8 or 11 kHz restores the
original bytes before the host is reloaded.

This host reload is necessary because an already-loaded `.SYN` module keeps its
code and tables in process memory; changing the file on disk cannot safely turn
that live instance into the patched native-16 engine. Restarting the isolated
host lets Eloquence load the correct module normally, avoids unsupported live
patching of proprietary in-memory code/data, and makes the operation reversible.
After reinitialization the add-on restores the language, voice variant/synthesis
model, and user voice parameters, then applies ECI parameter 5 for 16 kHz.

## Final tuning

The v20 native-16 tuning includes:

- the sixth cascade formant enabled;
- a small general consonant/noise gain increase (+1.5 dB);
- focused tuning of parallel stages 5 and 6 for sibilants;
- for all languages except Italian, an 80% native / 20% shaped blend for the
  stage-5/6 sibilance component;
- Italian retains the stronger shaped sibilance treatment that matched its
  native 16 kHz output best;
- no global voiced-source attenuation.

The patch files contain only the byte-level differences needed to activate and
tune the native 16 kHz path. The original proprietary `.SYN` data is not stored
in the repository.

## Native-s comparison mode

An experimental second native-16 setting changes only the final sibilance blend
from 80% native / 20% shaped to 100% native / 0% shaped. The blend is performed
between two phase-related signals; frequency-response analysis shows that the
20% shaped component progressively cancels energy above roughly 5.5 kHz. The
comparison setting removes that cancellation at its source while deliberately
keeping the successful separate frication filter used by `f`, the sixth
cascade, the general consonant gain, and all other native-16 changes. The
established 16 kHz setting remains available for direct comparison.

`tools/make_native_s_patches.py` derives the `.p16n` files mechanically from the
established `.p16` files. It changes only the shaped-s blend factor and validates
the surrounding filter coefficient table before writing each patch.

## Full-band extension comparison mode

A further experimental setting combines the true native sibilance path with a
+10 dB high shelf applied to the complete summed 16 kHz signal. The transition
is centred at 4.8 kHz so that the newly available band above the original
11.025 kHz Nyquist limit is already close to the full boost and reaches +10 dB
from approximately 6 kHz onward. This affects every synthesis component in the
extension band, including frication, aspiration, and voiced energy, rather than
only the dedicated sibilance path. The filter state is preserved across audio
chunks and reset between Speech Generations.

Three additional comparison curves distribute the same final +10 dB boost over
two shelves so that the rise begins before the extension band:

| Setting | 3 kHz | 4 kHz | 5 kHz | 5.5 kHz | 6.5 kHz and above |
| --- | ---: | ---: | ---: | ---: | ---: |
| Gentle rise | +1.6 dB | +3.4 dB | +6.4 dB | +8.1 dB | about +10 dB |
| Medium rise | +2.6 dB | +4.6 dB | +7.5 dB | +8.8 dB | about +10 dB |
| Early rise | +3.9 dB | +5.9 dB | +8.4 dB | +9.3 dB | about +10 dB |

All three retain the true native sibilance patch and the established frication
treatment. They differ only in the full-output bandwidth balance.

## Measured voiced-energy reference

Two recordings of the same material, one native and one externally adjusted to
the preferred voiced-energy balance, were dynamically aligned at 10 ms
resolution. Their matched energy envelopes correlate at 0.95. Measurements over
272 matched voiced frames show that the target is closely represented by a
single broad +8 dB shelf centred at 3.43 kHz with a slope of 0.406. Its RMS error
against the measured half-kilohertz bands is approximately 0.19 dB.

The corresponding comparison mode retains the true native sibilance and the
established frication treatment. The reference recording was explicitly not a
target for consonant quality, so this curve establishes only the voiced-energy
balance; consonant noise requires a separate comparison against the original
11 kHz output.

## Sixth-cascade isolation

A further comparison mode uses the same measured voiced-energy curve, true
native sibilance, and established frication treatment, but restores the original
five-cascade count. Its `.p16b5` patch differs from the corresponding `.p16n`
patch by exactly one byte in the synthesis loop-bound instruction: five cascade
formants are processed instead of six. The separate PE section-count patch
remains at six so the injected `.xflt` section stays mapped and executable. This
isolates whether the sixth cascade causes the voiced high-frequency sizzle that
became audible after restoring the preferred upper-band energy.
